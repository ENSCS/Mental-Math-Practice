# Mental Math Practice (คณิตคิดเร็ว)

ชุดแบบฝึกหัดและข้อสอบจำลอง **คณิตคิดเร็ว / จินตคณิต** สำหรับเด็ก เปิดในเว็บเบราว์เซอร์ได้ทันที
ทุกครั้งที่เปิดหรือกดปุ่ม **"สุ่มโจทย์ใหม่"** จะได้โจทย์ชุดใหม่พร้อมเฉลย สั่งพิมพ์เป็น PDF หรือกระดาษ A4 ได้เลย

> **English summary:** Free, printable mental-math worksheets and mock level tests for children
> (abacus-style vertical addition/subtraction, multiplication and division). Every page is a single
> static HTML file that generates a new random problem set with an answer key on each load.
> No build step, no server-side code, no tracking.

---

## ใช้งานยังไง

1. เปิดหน้าแรก `index.html`
2. เลือกการ์ดของชุดที่ต้องการ
3. ใช้ปุ่มมุมขวาบนของหน้า
   - **สุ่มโจทย์ใหม่** ได้โจทย์ชุดใหม่ทันที
   - **พิมพ์ PDF** เปิดหน้าต่างพิมพ์ เลือก "Save as PDF" หรือพิมพ์ลงกระดาษ (ปุ่มจะไม่ติดไปในงานพิมพ์)
4. หน้าเฉลยจะอยู่ต่อจากหน้าโจทย์ (ข้อสอบวัดระดับ) หรืออยู่ท้ายหน้า (ชุดคณิตคิดเร็ว)

ทุกชุดมี **Test id** เช่น `2639-4R-5258` พิมพ์อยู่บนกระดาษทั้งหน้าโจทย์และหน้าเฉลย
ใช้จับคู่ว่าเฉลยแผ่นไหนเป็นของโจทย์แผ่นไหน (ดูรูปแบบรหัสในหัวข้อ [Test id](#test-id))

## การนำไปใช้งาน (สำหรับคนทั่วไป)

ไม่ต้องติดตั้งโปรแกรมอะไรเพิ่ม ใช้แค่เว็บเบราว์เซอร์ที่มีอยู่แล้วในเครื่อง (Chrome, Edge, Safari, Firefox)

### ขั้นที่ 1: ดาวน์โหลด
1. เข้าไปที่ https://github.com/ENSCS/Mental-Math-Practice
2. กดปุ่มสีเขียว **`<> Code`** (อยู่ด้านบน ขวามือ)
3. กด **Download ZIP**
4. จะได้ไฟล์ชื่อ `Mental-Math-Practice-main.zip` อยู่ในโฟลเดอร์ **Downloads (ดาวน์โหลด)**

### ขั้นที่ 2: แตกไฟล์ ZIP
- **Windows:** คลิกขวาที่ไฟล์ ZIP → เลือก **Extract All... (แตกไฟล์ทั้งหมด)** → กด **Extract**
- **Mac:** ดับเบิลคลิกที่ไฟล์ ZIP ได้เลย

จะได้โฟลเดอร์ `Mental-Math-Practice-main` ย้ายไปไว้ที่ไหนก็ได้ เช่น Desktop

> ⚠️ ต้องแตกไฟล์ก่อน ถ้าเปิดไฟล์จากใน ZIP ตรงๆ บางหน้าอาจทำงานไม่ครบ

### ขั้นที่ 3: เปิดใช้งาน
1. เข้าไปในโฟลเดอร์ `Mental-Math-Practice-main`
2. **ดับเบิลคลิกที่ไฟล์ `index.html`** หน้าเว็บจะเปิดขึ้นมาในเบราว์เซอร์
3. คลิกการ์ดชุดที่ต้องการ แล้วใช้ปุ่ม **สุ่มโจทย์ใหม่** / **พิมพ์ PDF** ได้เลย

ถ้าดับเบิลคลิกแล้วเปิดเป็นโปรแกรมอื่น (เช่น Notepad) ให้ **คลิกขวาที่ไฟล์ → Open with (เปิดด้วย) → เลือก Chrome หรือ Edge**

**ข้อควรรู้**
- **ไม่ต้องใช้เซิร์ฟเวอร์** ดับเบิลคลิกเปิดไฟล์ได้เลย
- **ไม่ต่ออินเทอร์เน็ตก็ใช้ได้** สุ่มโจทย์ เฉลย และพิมพ์ได้ครบ รูปแบบตัวอักษรอาจต่างไปเล็กน้อย แต่ไม่มีผลกับการใช้งาน
- **อยากได้โจทย์ชุดใหม่** กดปุ่ม **สุ่มโจทย์ใหม่** หรือกด **F5** (Mac กด **⌘ + R**)
- **สั่งพิมพ์** กด **พิมพ์ PDF** แล้วเลือกเครื่องพิมพ์ หรือเลือก **Save as PDF / บันทึกเป็น PDF** เพื่อเก็บไฟล์ไว้ส่งต่อ

## รายละเอียดแต่ละชุด

"บวกลบแนวตั้ง" คือโจทย์แบบจินตคณิต ตัวเลขเรียงลงมาในคอลัมน์ บางตัวมีเครื่องหมายลบ
ให้คิดจากบนลงล่างแล้วเขียนผลรวมในช่องล่างสุด **ทุกชุดรับประกันว่าคำตอบไม่ติดลบ**

### 🎮 Math Game — เกมฝึกคิดเลขบนจอ
- เลือกรูปแบบ: บวกล้วน / ลบล้วน / คละบวกลบ แบบ 2, 3, 4 หรือ 5 จำนวน
- เลือกจำนวนข้อ: 5, 10, 20, 50, 100, 200
- เลือกระดับ: ง่าย ⭐ / ปานกลาง ⭐⭐ / ยาก ⭐⭐⭐ (ปรับสัดส่วนโจทย์ง่าย-ปานกลาง-ยาก)
- ตัวเลขแต่ละตัวอยู่ระหว่าง 1–90
- ตอบด้วยแป้นตัวเลขบนจอ หรือคีย์บอร์ด (`0–9`, `Enter` ส่งคำตอบ, `Backspace` ลบ, `C` ล้าง)
- ตรวจคำตอบทันที ✅/❌ แสดงเฉลยเมื่อผิด มีตัวจับเวลา และสรุปคะแนน + เวลาเมื่อจบ

### ⚡ Practice Multiple — แบบฝึกหัดคูณเร็ว
- 8 หน้า หน้าละแม่: ×2 ถึง ×9
- แต่ละหน้าคือเลข 11–99 ทุกตัว (89 ข้อ) สลับลำดับแบบสุ่ม จัด 3 คอลัมน์
- ยังไม่มีหน้าเฉลย (โค้ดเฉลยมีอยู่แต่ปิดไว้)

### 📊 Math G4-Y7 Up — ข้อสอบวัดระดับ เกรด 4 (80 ข้อ, 5 นาที)
| ข้อ | โจทย์ | กติกา | คะแนน |
|---|---|---|---|
| 1–30 | คูณ | เลข 2 หลัก (15–99) × เลข 1 หลัก (2–9) | ข้อละ 1 |
| 31–60 | หาร | หารลงตัว ตัวหาร 2–9 ตัวตั้งไม่เกิน 999 | ข้อละ 1 |
| 61–70 | บวกลบแนวตั้ง | เลข 2 หลัก 4 แถว ลบได้ไม่เกิน 1 ตัว | ข้อละ 2 |
| 71–80 | บวกลบแนวตั้ง | เลข 2 หลัก 5 แถว ลบได้ไม่เกิน 2 ตัว | ข้อละ 2 |

### 🏆 Math G6 — ข้อสอบวัดระดับ เกรด 6 (60 ข้อ, 5 นาที)
| ข้อ | โจทย์ | กติกา | คะแนน |
|---|---|---|---|
| 1–20 | คูณ | เลข 3 หลัก (100–999) × เลข 1 หลัก (2–9) | ข้อละ 1 |
| 21–40 | หาร | หารลงตัว ตัวหาร 2–9 ตัวตั้งไม่เกิน 4 หลัก ผลลัพธ์ส่วนใหญ่ 3 หลัก (~20% เป็น 2 หลัก) ตัวเลขหลักพันมีลูกน้ำ เช่น 3,496 | ข้อละ 1 |
| 41–51 | บวกลบแนวตั้ง | เลข 2 หลัก 8 แถว | ข้อละ 2 |
| 52–60 | บวกลบแนวตั้ง | เลข 2 หลัก 9 แถว | ข้อละ 2 |

ในข้อ 41–60 ทุกกลุ่ม 5 ข้อ คอลัมน์ที่ 2 และ 4 (ข้อ 42, 44, 47, 49, 52, 54, 57, 59) มีเลขลบ 3 ตัว
ข้ออื่นเป็นบวกล้วน แถวแรกไม่ติดลบ และผลรวมระหว่างทางไม่ติดลบ (เหมือนการคิดด้วยลูกคิด)

### 📝 Math Test 7Y / ⏳ Math Test 7Y-5 — คณิตคิดเร็ว อายุ 7 ปี
ตัวเลขทุกตัวเป็นเลข 1 หลัก (1–9) มี 3 ชุด ชุดละ 20 ข้อ และตารางเฉลยท้ายหน้า

| ชุด | 7Y | 7Y-5 (ซ้อมระดับ 8 ปี) |
|---|---|---|
| ข้อ 1–20 | 5 แถว ลบ ≤ 1 ตัว | 6 แถว ลบ ≤ 2 ตัว |
| ข้อ 21–40 | 6 แถว ลบ ≤ 2 ตัว | 7 แถว ลบ ≤ 2 ตัว |
| ข้อ 41–60 | 7 แถว ลบ ≤ 2 ตัว | 8 แถว ลบ ≤ 2 ตัว |
| คำตอบสูงสุด | 59 | 72 |

### 📚 Math Test 8Y — คณิตคิดเร็ว อายุ 8 ปี (60 ข้อ)
- ข้อ 1–20: เลข 1 หลัก 6 แถว, ข้อ 21–40: 7 แถว, ข้อ 41–60: 8 แถว (ลบ ≤ 2 ตัว)
- ข้อ 46–50 และ 56–60 เป็น **ข้อพิเศษ**: 5 แถว ผสมเลข 2 หลัก 3 ตัว + เลข 1 หลัก 2 ตัว (ลบ ≤ 1 ตัว)

### ⚡ Math Test 8Y (Row 3) — อายุ 8 ปี แบบยากขึ้น
- เหมือน 8Y แต่ข้อปกติเป็น 8 แถวทุกชุด
- ข้อพิเศษ (ผสมเลข 2 หลัก) เพิ่มเป็นข้อ 6–10, 16–20, 26–30, 36–40, 46–50, 56–60

### ⚡ Math Test 8Y (1 Min) — อายุ 8 ปี จับเวลา 1 นาที
- 40 ข้อ ข้อละ 2 คะแนน จัด 4 แถว แถวละ 10 ข้อ กระดาษ A4 แนวตั้ง
- 5 ข้อแรกของแต่ละแถว: เลข 1 หลัก 8 แถว (ลบ ≤ 2 ตัว)
- 5 ข้อหลังของแต่ละแถว: เลข 2 หลัก 3 ตัว + เลข 1 หลัก 2 ตัว (ลบได้เฉพาะเลข 2 หลัก ไม่เกิน 1 ตัว)

## Test id

รูปแบบ `YYWW-DH-MMSS` สร้างจากเวลาที่เปิดหน้า เช่น `2639-4R-5258`

| ส่วน | ความหมาย | ตัวอย่าง |
|---|---|---|
| `YY` | ปี ค.ศ. 2 หลักท้าย | `26` = 2026 |
| `WW` | สัปดาห์ของปี (ISO week) | `39` |
| `D` | วันในสัปดาห์ 1=จันทร์ … 7=อาทิตย์ | `4` = พฤหัสบดี |
| `H` | ชั่วโมงเป็นตัวอักษร A=01 … W=23, Z=00 (เที่ยงคืน) | `R` = 18 นาฬิกา |
| `MMSS` | นาทีและวินาที | `5258` |

## สำหรับนักพัฒนา / AI

- **ไม่มี build, ไม่มี dependency, ไม่มีฐานข้อมูล** — ทุกหน้าเป็น HTML ไฟล์เดียว มี CSS และ JavaScript อยู่ในไฟล์
- เปิดผ่านเว็บเซิร์ฟเวอร์ใดก็ได้ (XAMPP, `python3 -m http.server`, GitHub Pages)
  ถ้าเปิดแบบ `file://` บางเบราว์เซอร์จะไม่โหลดฟอนต์ใน `fonts/`
- ไม่มีโค้ดฝั่งเซิร์ฟเวอร์ (ไม่มี PHP) หน้าแรกคือ `index.html` วางบนโฮสต์ไหนก็เปิดเป็นหน้าแรกของโฟลเดอร์ได้ทันที
- โจทย์สุ่มด้วย `Math.random()` ฝั่งเบราว์เซอร์ ไม่มี seed จึงสร้างชุดเดิมซ้ำไม่ได้ (Test id ใช้ระบุชุด ไม่ได้ใช้สร้างซ้ำ)
- หน้าข้อสอบวัดระดับ (`mathg4y7up.html`, `mathg6.html`) มีโครงเดียวกัน:
  - `generateProblemData()` สุ่มโจทย์เก็บไว้ใน `allData = { mult, div, abacus }`
  - `createPageHTML(isAnswerKey)` สร้างโครงหน้า
  - `fillPageContent(isAnswerKey)` เติมโจทย์ และเติมคำตอบเมื่อเป็นหน้าเฉลย
  - ถ้าจะทำระดับใหม่ ให้คัดลอกไฟล์ใดไฟล์หนึ่ง แล้วแก้ช่วงตัวเลขใน `generateProblemData()`
- หน้าคณิตคิดเร็ว (`mathtest*.html`) ใช้ `generate(containerId, startNo, rows, maxMinus)`
  สุ่มซ้ำจนกว่าคำตอบจะไม่ติดลบ แล้วสร้างตารางเฉลยท้ายหน้า
- กระดาษตั้งค่าด้วย `@media print` และ `@page { size: A4 ... }` ในแต่ละไฟล์
